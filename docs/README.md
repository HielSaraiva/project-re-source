# Documentação do Projeto Resource System

Bem-vindo à documentação do projeto. Aqui você encontra todos os artefatos de documentação organizados por tipo.

## Estrutura

```
docs/
├── README.md                        # Este arquivo
├── regras-de-negocio/               # Regras de negócio do sistema
│   └── RN-00X-TEMPLATE.md
├── casos-de-uso/                    # Casos de uso do sistema
│   └── UC-00X-TEMPLATE.md
└── arquitetura/                     # Decisões e diagramas de arquitetura
    └── arquitetura.md
```

## Convenções de Nomenclatura

- **Regras de Negócio:** `RN-001-nome-da-regra.md`
- **Casos de Uso:** `UC-001-nome-do-caso-de-uso.md`
